Forsage Import – վեբ կայք
Functional Specification
Ընդհանուր նկարագրություն (Overview)
Նպատակն է ստեղծել ժամանակակից, արագ և վստահություն ներշնչող մեկ էջանոց վեբ կայք՝ Forsage Import ընկերության համար։ Ընկերությունը զբաղվում է  ավտոաճուրդներից, մասնավորապես Copart և IAAI հարթակներից, ավտոմեքենաների ընտրությամբ, գնմամբ և Հայաստան ներմուծմամբ։
Կայքը պետք է այցելուին պարզ ներկայացնի ծառայության ամբողջ ընթացքը, օգնի մոտավոր հաշվարկել ավտոմեքենայի ձեռքբերման և ներմուծման ընդհանուր ծախսերը, ինչպես նաև հնարավորություն տա արագ կապ հաստատել ընկերության հետ կամ լրացնել պատվերի հայտ։
Կայքի հիմնական նպատակները
Ներկայացնել Forsage Import ընկերությունը և ձևավորել վստահություն։
Ներկայացնել ԱՄՆ աճուրդներից ավտոմեքենա պատվիրելու ծառայությունը։
Բացատրել աշխատանքի փուլերը՝ մեքենայի ընտրությունից մինչև Հայաստան առաքում։
Տրամադրել ավտոմեքենայի ընդհանուր արժեքի մոտավոր հաշվիչ։

2. Կարճ ներկայացում (ընկերության մասին)
Forsage Import-ի կարճ ներկայացում՝ 3–5 պարբերությամբ։
Ընկերության գործունեության հիմնական ուղղությունը՝ արտասահմանյան երկրների ավտոմեքենաների ներմուծում։
3. Հիմնական ծառայություններ
Ընդհանուր ծառայությունների ներկայացում, օրինակ՝
Ավտոմեքենայի որոնում և ընտրություն։
Copart, Manheim և IAAI աճուրդների լոտերի վերլուծություն։
Աճուրդին մասնակցություն և գնում։
VIN և մեքենայի պատմության ստուգում։
Ներքին և ծովային տեղափոխման կազմակերպում։
Մաքսազերծման և փաստաթղթերի բոլոր ձևակերպմամբ, մինչև բանալիների հանձնում։
4. Ինչպես է աշխատում
Քայլ 1՝ հաճախորդը նշում է ցանկալի մեքենան և բյուջեն։
Քայլ 2՝ թիմը գտնում և առաջարկում է համապատասխան տարբերակներ։
Քայլ 3՝ կատարվում է մեքենայի պատմության և վնասվածքների նախնական ուսումնասիրություն։
Քայլ 4՝ հաճախորդի հաստատումից հետո կատարվում է աճուրդային հայտը։
Քայլ 5՝ կազմակերպվում է վճարումը, տեղափոխումը և առաքումը, մաքսազերծումը։
Քայլ 6՝ մեքենան հասնում է Հայաստան, մաքսազերծվում է և փոխանցվում հաճախորդին։

մեքենայի պատմության ստուգում և ամբողջական ուղեկցում։
7. Հայտի ձև, Դիմում 
Կայքում պետք է ստեղծվի ավտոմեքենայի ներմուծման արժեքի հաշվարկման ձև՝ հետևյալ դաշտերով․
Մեքենայի արժեքը — թվային դաշտ, USD արժույթով
Աճուրդ — ընտրություն՝ Copart կամ IAAI
Աճուրդի միջնորդավճար — թվային դաշտ
Աճուրդի վայր — ընտրացանկ՝ աճուրդի տեղակայման վայրերով
Տեղափոխման վճար — թվային դաշտ
Շարժիչի տեսակ — ընտրացանկ, օրինակ՝ բենզին, դիզել, հիբրիդ, էլեկտրական
Մեքենայի տարիքային խումբ — ընտրացանկ, օրինակ՝ մինչև 3 տարի, 3–5 տարի, 5 տարուց ավելի
Արտադրության տարի — ընտրացանկ
Շարժիչի ծավալ — թվային դաշտ՝ լիտրով կամ սմ³-ով
Տրանսպորտային միջոցի տեսակ — ընտրացանկ, օրինակ՝ սեդան, ամենագնաց, պիկապ, մինիվեն և այլն
Ապահովագրություն — checkbox, որը հնարավոր կլինի միացնել կամ անջատել
«Հաշվել» կոճակ
Բոլոր անհրաժեշտ դաշտերը լրացնելուց հետո օգտատերը սեղմում է «Հաշվել» կոճակը։
Հաշվարկից հետո նույն էջում պետք է բացվի արդյունքների հատվածը, որտեղ առանձին ներկայացված կլինեն՝
Մեքենայի արժեքը
Աճուրդի միջնորդավճարը
Ծառայության վճարը
Տեղափոխման արժեքը
Ապահովագրության արժեքը
Ընդհանուր արժեքը՝ մինչև մաքսազերծում
Մաքսային վճարները՝ իրավաբանական և ֆիզիկական անձանց համար
Վերջնական ընդհանուր արժեքը յուրաքանչյուր տարբերակի համար
Արդյունքի յուրաքանչյուր տարբերակի ներքևում պետք է լինի «Ներբեռնել» կոճակ՝ հաշվարկը PDF ձևաչափով պահպանելու համար։
